# Food Delivery System

A simple Java application that simulates a food ordering and delivery system.

## Features
- Add meals and drinks to orders.
- Calculate order totals and delivery fees.
- Support cash and card payments.
- Manage order statuses.
- Support standard and express delivery.

## Technologies
- Java
- Object-Oriented Programming (OOP)
- Eclipse IDE
